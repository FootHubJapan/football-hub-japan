# 試合終了後の自動更新システム

## 概要

試合が終了した後に、自動的に選手データを更新するシステムです。

## 実行方法

### 手動実行

```bash
npm run update-finished-matches
```

または

```bash
node update-finished-matches.js
```

### 自動実行（サーバー起動時）

`index.js`が起動すると、自動的に以下のスケジュールで実行されます：

1. **サーバー起動1分後**: 初回実行
2. **その後1時間ごと**: 定期実行

## 動作内容

1. 主要リーグ（プレミアリーグ、ラ・リーガ、セリエA、ブンデスリーガ、リーグ・アン、J1リーグ）の過去72時間以内に終了した試合を取得
2. 各試合の選手統計を取得
3. 選手データベース（`data/players.json`）を更新
4. 2025/26シーズンの統計を更新

## 設定

### 検索範囲

- **期間**: 過去72時間以内に終了した試合
- **シーズン**: 2025/26シーズン（8月以降は新しいシーズン、7月以前は前シーズン）

### 対象リーグ

- Premier League (39)
- La Liga (140)
- Serie A (135)
- Bundesliga (78)
- Ligue 1 (61)
- J1 League (169)

## Renderでの自動実行

RenderのCron Jobsを使用して、定期的に実行することもできます：

1. Renderダッシュボードで「Cron Jobs」を追加
2. コマンド: `node update-finished-matches.js`
3. スケジュール: `0 * * * *` (毎時実行)

## 注意事項

- APIレート制限: Pro Plan (300 r/m) を考慮して、リクエスト間に200msの遅延を設定
- データの反映: 試合終了後、APIにデータが反映されるまで数時間かかる場合があります
